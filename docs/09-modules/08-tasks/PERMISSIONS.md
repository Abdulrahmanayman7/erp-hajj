# Tasks — Permissions

> **Status:** Approved
> **Last updated:** 2026-08-06

| Permission | Purpose |
|---|---|
| `tasks.view` | List/view tasks |
| `tasks.create` | Create tasks |
| `tasks.update` | Update task data |
| `tasks.assign` | Assign/reassign responsible persons (audited) |
| `tasks.change_status` | Change task status |
| `tasks.complete` | Complete tasks (audited) |
| `tasks.delete` | Delete tasks |
