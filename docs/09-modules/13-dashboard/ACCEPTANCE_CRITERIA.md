# Dashboard — Acceptance Criteria

> **Status:** Draft
> **Last updated:** 2026-08-06

- [ ] Dashboard accessible only with `dashboard.view`.
- [ ] Every widget's data is computed from the current tenant only.
- [ ] Widgets appear only when the viewer holds the underlying module's view permission.
- [ ] Indicators are correct against module data (spot-checked per widget).
- [ ] No future-scope widgets exist (no tracking, GPS, financial analytics, AI, command center).
- [ ] Widget links navigate to correctly filtered module pages.
- [ ] Loading/empty/error states render via shared components.
