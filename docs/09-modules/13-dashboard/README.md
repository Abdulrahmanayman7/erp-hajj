# Module: Administrative Dashboard (لوحة التحكم الإدارية)

> **Status:** Documented — not implemented
> **Last updated:** 2026-08-06

## Purpose

Present administrative indicators from the MVP modules in one tenant-scoped, permission-aware dashboard. This is an **administrative** dashboard — not a command center.

## Possible MVP widgets

Active users · Employees · Supervisors · Active contracts · Contracts nearing expiry · Open tasks · Overdue tasks · Upcoming meetings · Recent decisions · Low-stock alerts · Assigned assets · Recent audit activity (permission-controlled)

## Explicitly not included

Bus tracking · Pilgrim GPS · Emergency operations · Financial analytics · AI predictions · Full Command Center
