## Pages

- **Document center** — Data Table with search and filters (category, type, linked entity, confidentiality, date); upload via shared File Upload component.
- **Document details** — metadata, linked entity link, download action, archive action, audit history panel.
- **Categories management** — simple list for `documents.manage_categories` holders.
- **Embedded attachments widget** — reusable component used by other modules (contracts, meetings, tasks, employees...) to list/upload linked documents.

## Rules

- Confidentiality badge displayed; unauthorized documents never listed.
- Downloads through the authorized endpoint only — no direct storage links.
- Archive uses Confirmation Dialog.
