# Organizational Structure — Permissions

> **Status:** Approved
> **Last updated:** 2026-08-06

| Permission | Purpose |
|---|---|
| `departments.view` | View the organizational structure |
| `departments.create` | Create organizational units |
| `departments.update` | Update/move units |
| `departments.delete` | Delete units (restricted; audited) |

Note: the `departments.*` prefix covers all organizational unit types (department/section/unit).
