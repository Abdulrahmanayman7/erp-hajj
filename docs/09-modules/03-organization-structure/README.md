# Module: Organizational Structure (الهيكل التنظيمي)

> **Status:** Documented — not implemented
> **Last updated:** 2026-08-06

## Purpose

Model each tenant's flexible organizational hierarchy: departments, sections, units, and positions.

## Scope

- Organizational units with parent-child relationships and no hardcoded depth limit.
- Unit types: Department (إدارة), Section (قسم), Unit (وحدة).
- Positions / job titles (منصب / مسمى وظيفي).
- Assignment basis for employees (primary unit, position, direct manager — managed in the employees module).

## Out of scope

- Multiple simultaneous assignments per employee (future scope unless approved).
- Org-chart visualization beyond a basic tree: TBD.
