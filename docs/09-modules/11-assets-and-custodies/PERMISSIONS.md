# Assets and Custodies — Permissions

> **Status:** Approved
> **Last updated:** 2026-08-06

| Permission | Purpose |
|---|---|
| `assets.view` | List/view assets and custody history |
| `assets.create` | Register assets |
| `assets.update` | Update asset data |
| `assets.delete` | Delete assets (restriction rules TBD) |
| `assets.assign` | Assign an asset as custody (audited) |
| `assets.return` | Process custody return (audited) |
| `assets.retire` | Retire assets (audited) |
