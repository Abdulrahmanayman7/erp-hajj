# Meetings — Acceptance Criteria

> **Status:** Draft
> **Last updated:** 2026-08-06

- [ ] Meetings CRUD with the five statuses works, tenant-scoped.
- [ ] Attendees, agenda items, minutes, and recommendations manageable with their dedicated permissions.
- [ ] Meeting completion is audited.
- [ ] A completed meeting can be referenced by one or more decisions.
- [ ] Deleting a completed meeting is impossible without privileged permission, and is audited when performed.
- [ ] Cancellation requires `meetings.cancel` and is audited.
- [ ] Attachments work via the documents module.
- [ ] Cross-tenant access returns `404`.
