# Module: Meetings (الاجتماعات)

> **Status:** Documented — not implemented
> **Last updated:** 2026-08-06

## Purpose

Manage formal administrative meetings with agendas, attendees, minutes, and recommendations — the starting point of the governance chain (Meeting → Recommendation → Decision → Tasks).

## Scope

- Meetings CRUD with statuses: Draft, Scheduled, In Progress, Completed, Cancelled.
- Attendee management, agenda items, minutes (محضر), recommendations (توصيات).
- Attachments via the documents module.
- Creating decisions from completed meetings.

## Out of scope

- Calendar integrations, video conferencing (future scope / not specified).
